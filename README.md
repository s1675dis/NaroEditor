# NaroEditor

小説家になろう・カクヨム・Pixiv 向けルビ・傍点記法に対応した、Windows 用日本語テキストエディターです。

## インストール

[Releases](https://github.com/s1675dis/NaroEditor/releases) ページから最新の `NaroEditor.exe` をダウンロードして実行してください。インストール不要です。

> **初回起動について**  
> 初回はファイルの展開処理が走るため起動に時間がかかります（30秒程度）。2回目以降は通常速度で起動します。

## 機能

- **マルチタブ / 分割ペイン** — タブを左右・上下に分割して同時編集
- **プロジェクトツリー** — フォルダをプロジェクトとして登録し、ファイルをツリー表示。エクスプローラーの変更をリアルタイムで反映
- **ルビ・傍点の挿入** — なろう/カクヨム・Pixiv 形式に対応したショートカット挿入
- **リアルタイムプレビュー** — フロート / ドッキング切り替え可能。5テーマ対応（小説家になろう・カクヨム・Pixiv小説・Pixiv Fanbox）。25〜100% の表示倍率変更に対応
- **クラッシュリカバリー** — 30秒ごとに自動保存。強制終了後の次回起動時に未保存の内容を復元
- **文字コード自動判別** — UTF-8・Shift_JIS・EUC-JP などを自動検出して開く
- **文字数・行数カウント** — ステータスバーにリアルタイム表示
- **セッション復元** — 前回終了時のタブを次回起動時に自動で復元

## ショートカット一覧

### ファイル

| 操作 | ショートカット |
|---|---|
| 新規タブ | `Ctrl+N` |
| ファイルを開く | `Ctrl+O` |
| 上書き保存 | `Ctrl+S` |
| 名前を付けて保存 | `Ctrl+Shift+S` |
| タブを閉じる | `Ctrl+W` |

### 編集

| 操作 | ショートカット |
|---|---|
| 元に戻す | `Ctrl+Z` |
| やり直し | `Ctrl+Y` |
| 切り取り | `Ctrl+X` |
| コピー | `Ctrl+C` |
| 貼り付け | `Ctrl+V` |
| 引用符付き貼り付け | `Ctrl+Q` |
| 行削除 | `Ctrl+Enter` |
| すべて選択 | `Ctrl+A` |
| 書き換え禁止（読み取り専用） | `Ctrl+Shift+N` |
| 検索 | `Ctrl+F` |
| 置換 | `Ctrl+R` |

### テキスト変換

| 操作 | ショートカット |
|---|---|
| 小文字に変換 | `Ctrl+L` |
| 大文字に変換 | `Ctrl+Shift+L` |
| 半角に変換 | `Ctrl+G` |
| 全角に変換 | `Ctrl+Shift+G` |
| 空白インデント | `Ctrl+Shift+I` |
| 空白逆インデント | `Ctrl+Shift+U` |
| 改行削除 | `Ctrl+Shift+T` |

### 記法挿入

| 操作 | ショートカット |
|---|---|
| ルビ（なろう / カクヨム） | `Alt+R` |
| ルビ（Pixiv） | `Alt+E` |
| 傍点（なろう / カクヨム） | `Alt+/` |
| 傍点（Pixiv） | `Alt+.` |

### 表示

| 操作 | ショートカット |
|---|---|
| プレビューの表示 / 非表示 | `Ctrl+Shift+P` |

### プロジェクトツリー

| 操作 | 方法 |
|---|---|
| ファイルを開く | クリック |
| フォルダの展開 / 折りたたみ | クリック |
| 名前を変更 | `F2` キー または右クリックメニュー |
| 新規フォルダ / ファイル作成 | 右クリックメニュー |
| 削除 | 右クリックメニュー |
| エクスプローラーで開く | 右クリックメニュー |

## 設定ファイルの保存場所

`%APPDATA%\NaroEditor\config.json`

プロジェクトフォルダ、タブのセッション情報、ウィンドウ位置などが保存されます。

## 変更履歴

### v1.2.9

- **テスト**: v1.2.8 アップデート機構の動作確認用リリース

### v1.2.8

- **バグ修正**: アップデート後の起動時に python DLL 読み込みが失敗する問題を修正
  - `subprocess.Popen(env=None)` では Win32 環境ブロックから `_MEIPASS2` が除去されないため、`env=` に明示的な辞書を渡して除外するよう変更
  - C# アップデータ側でも `UseShellExecute=false` + `_MEIPASS2` 削除を追加（二重防衛）

### v1.2.7

- **バグ修正**: アップデート後の起動時に python DLL の読み込みが失敗する問題を修正
  - アップデータ起動前に `_MEIPASS2` 環境変数を削除し、新 NaroEditor.exe が旧 `_MEI*` フォルダを参照しないよう対処

### v1.2.6

- **バグ修正**: NaroEditorUpdater.exe が Windows Defender にウィルスとして誤検知される問題を修正
  - アップデータを PyInstaller（Python）から .NET Framework 4.x C# に書き直し、実行ファイルサイズを 12MB → 61KB に削減
  - ネットワーク処理（EXE ダウンロード）を NaroEditor 本体側に移管し、アップデータはファイル置換と再起動のみを担当するシンプルな実装に変更

### v1.2.5

- **アップデート機構を刷新**: NaroEditor.exe 内部でダウンロード・置換を行う方式から、独立したアップデータプロセス（NaroEditorUpdater.exe）を起動する方式に変更
  - 初回起動時に `%APPDATA%\NaroEditor\NaroEditorUpdater.exe` へ自動展開
  - アップデート時は NaroEditor が PID・URL・保存先をアップデータに渡して終了。アップデータが NaroEditor の終了を確認してからダウンロード・置換・再起動を実行
  - 異なるプロセスで動作するため PyInstaller の環境変数継承による DLL 読み込み失敗を根本解消

### v1.2.4

- **バグ修正**: 自動アップデート後の再起動時に Python DLL 読み込みが失敗する問題を修正
  - 更新スクリプトをバッチファイルから PowerShell に変更
  - `_MEIPASS2` 環境変数（PyInstaller が子プロセスに継承する旧展開フォルダのパス）を起動前にクリア
  - `Unblock-File` でダウンロードファイルの Zone.Identifier（Web マーク）を除去
  - `Start-Process` でクリーンなプロセスコンテキストから新バージョンを起動

### v1.2.3

- **バグ修正**: 自動アップデート後の再起動時に Python DLL の読み込みに失敗する問題を修正（旧バージョンの展開フォルダを更新前に削除するよう変更）

### v1.2.2

- **新機能**: 自動アップデート機能を追加。起動時に GitHub Releases を確認し、新バージョンがある場合はダウンロード・上書き更新を実行
- **新機能**: ヘルプメニューに「アップデートを確認」を追加。手動でアップデートを確認可能
- **バグ修正**: 傍点（なろう/カクヨム）を選択範囲に適用した際、改行やスペースにも傍点が振られていた問題を修正
- **パフォーマンス改善**: 文字入力時のプレビュー更新を高速化（同一行数の場合はドキュメント再構築をスキップ）

### v1.2.1

- **バグ修正**: 改行削除（非選択時）がアンドゥできなかった問題を修正
- **バグ修正**: 「名前を付けて保存」ダイアログをキャンセルしてもタブが閉じられていた問題を修正
- **バグ修正**: 2ペイン時にタブを閉じる・ドラッグ移動した際、空になった左ペインではなく右ペインに新規タブが開いていた問題を修正
- **バグ修正**: クラッシュ復元後の起動時に不要な空タブが追加されていた問題を修正
- **バグ修正**: フロートプレビューウィンドウが保存済みズーム倍率を無視して常に 880px で開いていた問題を修正

### v1.2.0

- **クラッシュリカバリー** — 30秒ごとに編集中の内容を自動保存。PCトラブルや強制終了後の次回起動時に、未保存の内容を復元するか選択できるダイアログを表示
- **プレビュー倍率変更** — プレビュー下部の `−` / `+` ボタンで表示倍率を 25% / 50% / 75% / 100% の4段階で変更可能。フォントは変えず全体を縮小。倍率はドック・フロートのウィンドウ幅に連動し、設定は次回起動時も記憶

### v1.1.0

- プレビューエンジンを QTextBrowser ベースに刷新（QtWebEngine 依存を廃止）
- 起動時のセッション復元を遅延処理に変更し、ウィンドウ表示を高速化
- 内部コードの整理・デッドコード除去

### v1.0.0

- 初回リリース
